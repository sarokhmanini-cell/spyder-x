# SPIDBRICK — متجر ستريتوير مجاني على GitHub Pages

> WEAR THE DARKNESS

متجر إلكتروني ثابت (Static) بالكامل: HTML5 + CSS3 + JavaScript بدون تثبيت، بدون خادم، بدون قاعدة بيانات، بدون خدمات مدفوعة.
الطلبات تُرسل عبر **واتساب** بطريقة **الدفع عند الاستلام (COD)**.

---

## 1. ما الذي يحتويه المشروع؟

```
spidbrick/
├── index.html              الصفحة الرئيسية
├── shop.html               المتجر (فلترة، بحث، ترتيب)
├── product.html            تفاصيل المنتج (?id=...)
├── cart.html               السلة
├── checkout.html           إتمام الطلب (COD + واتساب)
├── order-confirmation.html تأكيد الطلب
├── about.html              عن العلامة
├── contact.html            تواصل معنا
├── size-guide.html         دليل المقاسات
├── faq.html                الأسئلة الشائعة
├── admin.html              إدارة المنتجات (محلية، للتجربة والإعداد)
├── css/style.css           التصميم
├── js/
│   ├── config.js           ⭐ إعدادات المتجر (الرقم، الانستغرام، التوصيل، الولايات)
│   ├── store.js            الكتالوج، السلة، الرسالة، الأدوات
│   ├── layout.js           الهيدر والفوتر المشتركان
│   ├── home.js, shop.js, product.js, cart.js, checkout.js,
│   │   confirmation.js, contact.js, admin.js
├── data/products.json      ⭐ كتالوج المنتجات (عدّله بمنتجاتك)
├── assets/
│   ├── favicon.svg
│   └── products/           صور المنتجات (SVG تجريبية، استبدلها بصورك JPG/PNG/WEBP)
├── .nojekyll
└── README.md
```

لا يوجد أي خطوة بناء (Build). كل شيء جاهز بمجرد رفع الملفات.

## 2. قبل النشر: ضبط الإعدادات الأساسية

افتح **`js/config.js`** وعدّل:

| الإعداد | المعنى | مثال |
|---|---|---|
| `whatsappNumber` | رقم واتساب المتجر بالصيغة الدولية **بدون + ولا مسافات** | `213555123456` (الرقم بدون الصفر الأول) |
| `instagram` | رابط حسابك | `https://www.instagram.com/spidbrick` |
| `tiktok` | رابط حسابك | `https://www.tiktok.com/@spidbrick` |
| `defaultDeliveryFee` | التوصيل الافتراضي بالدينار | `600` |
| `deliveryFees` | تكلفة التوصيل لكل ولاية (المفتاح رمز الولاية `"16"`) | `"16": 500` |
| `freeDeliveryThreshold` | التوصيل مجاني فوق هذا المبلغ (`null` للإلغاء) | `15000` |

> ⚠️ **الرقم الافتراضي `213000000000` تجريبي.** إذا لم تغيّره، يعطّل الموقع زر إرسال الطلب ويظهر تنبيهاً. هذا مقصود حتى لا تضيع الطلبات.

## 3. إضافة وتعديل المنتجات

### الطريقة الأولى: تعديل `data/products.json` مباشرة (الأفضل للنشر)

كل منتج بهذا الشكل:

```json
{
  "id": "tee-web-01",
  "name": "تيشيرت شبكة الظل",
  "category": "tees",
  "price": 3200,
  "salePrice": null,
  "description": "وصف المنتج...",
  "details": ["قطن 100%", "قصة واسعة"],
  "colors": [{ "name": "أسود", "hex": "#0b0b0d" }],
  "images": ["assets/products/tee-front.jpg", "assets/products/tee-back.jpg"],
  "stock": { "S": 6, "M": 10, "L": 8, "XL": 4, "XXL": 0 },
  "featured": true,
  "bestSeller": true,
  "createdAt": "2026-10-01"
}
```

- **`id`**: فريد لكل منتج، بدون مسافات (يُستعمل في الرابط).
- **`category`**: واحد من `tees` و`hoodies` و`pants` و`jackets`.
- **`salePrice`**: سعر التخفيض، أو `null` إن لم يوجد تخفيض. يجب أن يكون أقل من `price`.
- **`stock`**: عدد القطع لكل مقاس. الصفر يعني أن المقاس نافد ولا يُضاف للسلة.
- **`images`**: أول صورة للغلاف، والثانية تظهر عند مرور الفأرة في المتجر.
- **`featured`** يظهر المنتج في الصفحة الرئيسية، و**`bestSeller`** يظهره في "الأكثر مبيعاً".

لاستبدال الصور: ضع صورك في `assets/products/` وغيّر المسارات. الصور بصيغة JPG أو WEBP بعرض حوالي 800 بكسل تحمّل بسرعة.

> إذا أردت صوراً مختلفة لكل لون، أضف حقل `colorImages` بهذا الشكل:
> `"colorImages": { "أسود": ["assets/products/x-black-1.jpg"], "بنفسجي": ["assets/products/x-purple-1.jpg"] }`

### الطريقة الثانية: صفحة `admin.html` (للتجربة والإعداد)

1. افتح `admin.html` على موقعك.
2. عدّل أو أضف أو احذف المنتجات، وغيّر الأسعار والمخزون وأضف الصور.
3. اضغط **تصدير JSON** فيُنزَّل ملف `products.json`.
4. ضع الملف في مستودعك مكان `data/products.json` وارفعه (انظر القسم 5).

> ⚠️ **تنبيه أمني وصدق:** صفحة الإدارة تعمل **داخل متصفحك فقط**. التعديلات تُحفظ في LocalStorage لهذا المتصفح، ولا تصل إلى الزبائن ولا إلى المستودع. ليس فيها تسجيل دخول لأن أي شيء داخل الموقع الثابت يمكن قراءته. صفحة الإدارة هي للتجربة وإعداد الكتالوج، وليست نظام إدارة مشتركاً.
> ملاحظة: إذا عدّلت المنتجات محلياً، فالمتصفح يعرض النسخة المحلية وليس الملف الأصلي، إلى أن تضغط **إعادة الضبط**.

## 4. الدفع عند الاستلام عبر واتساب (كيف يعمل؟)

1. الزبون يضيف المنتجات للسلة ويملأ الاسم والهاتف والولاية والبلدية والعنوان.
2. الموقع يتحقق من المدخلات (رقم جزائري صحيح، حقول مطلوبة، ومخزون متوفر).
3. يُنشئ رقم طلب (مثل `SB-251112-K7QX`) ويُعدّ رسالة واتساب تحتوي كل التفاصيل والمجموع والتوصيل.
4. يفتح واتساب برسالة **جاهزة**، والزبون يضغط "إرسال".
5. صفحة التأكيد تعرض الطلب وزر إعادة الإرسال إن لزم.

**ما لا يفعله الموقع:** لا يحفظ الطلب في قاعدة بيانات، ولا يتحقق من الدفع، ولا يرسل بريداً. الطلب يصل إليك في واتساب فقط. لذلك احتفظ بالمحادثات، وأكّد كل طلب مع الزبون.

## 5. النشر المجاني على GitHub Pages (خطوة بخطوة)

### أ) إنشاء الحساب والمستودع
1. أنشئ حساباً مجانياً على <https://github.com>.
2. اضغط **New** (مستودع جديد). سمّه مثلاً `spidbrick`.
3. اختر **Public** (ضروري لـ GitHub Pages المجاني)، ثم **Create repository**.

### ب) رفع الملفات
**الطريقة السهلة (بدون أدوات):**
1. داخل المستودع اضغط **uploading an existing file**.
2. اسحب **محتويات** مجلد `spidbrick` (وليس المجلد نفسه) إلى الصفحة. يجب أن يكون `index.html` في جذر المستودع.
3. اكتب رسالة مثل `First version` ثم **Commit changes**.

**الطريقة بـ Git:**
```bash
cd spidbrick
git init
git add .
git commit -m "First version"
git branch -M main
git remote add origin https://github.com/USERNAME/spidbrick.git
git push -u origin main
```

### ج) تفعيل GitHub Pages
1. في المستودع اضغط **Settings** (الإعدادات).
2. من القائمة الجانبية اختر **Pages**.
3. في **Build and deployment** → **Source** اختر **Deploy from a branch**.
4. **Branch**: اختر `main` و**/(root)** ثم **Save**.
5. انتظر من دقيقة إلى ثلاث دقائق. ستظهر رسالة: *Your site is live at ...*

### د) الحصول على رابط الموقع
الرابط يكون بهذا الشكل:

```
https://USERNAME.github.io/spidbrick/
```

- `USERNAME` هو اسم حسابك على GitHub.
- إذا سمّيت المستودع `USERNAME.github.io` فالرابط يصبح `https://USERNAME.github.io/` بدون اسم المستودع.
- الرابط الكامل موجود أيضاً في صفحة **Settings → Pages**.

### هـ) التحديثات لاحقاً
عدّل الملفات ثم ارفعها من جديد (Upload) أو `git push`. يُحدَّث الموقع تلقائياً خلال دقائق. إذا لم تظهر التغييرات فحاول تحديث الصفحة بقوة (Ctrl+F5) أو افتحها بنافذة خاصة.

## 6. إضافة الرابط إلى بايو إنستغرام وتيك توك

**Instagram:**
1. افتح التطبيق ← صورة ملفك ← **Edit profile** (تعديل الملف الشخصي).
2. ضع الرابط في خانة **Website** (موقع الويب) أو **Links** (الروابط).
3. احفظ. سيظهر الرابط تحت البايو.

**TikTok:**
1. افتح التطبيق ← **Profile** ← **Edit profile**.
2. اختر **Website** وأدخل الرابط.
3. إذا لم تظهر الخانة، فقد تحتاج إلى حساب **Business** أو **Creator** من الإعدادات (Settings and privacy ← Account). هذا تغيير مجاني.

> نصيحة: إذا أردت أكثر من رابط (المتجر + واتساب + آخر الإصدارات)، استعمل صفحة روابط مجانية مثل Linktree أو ضع رابط المتجر الرئيسي فقط.

## 7. الاختبار قبل النشر (قائمة تحقق)

- [ ] ضبطت `whatsappNumber` في `js/config.js` وتأكدت من أن الرقم يعمل في واتساب.
- [ ] أضفت منتجاتك إلى `data/products.json` واستبدلت الصور.
- [ ] جرّبت إضافة منتج للسلة، وتغيير الكمية، والحذف، والمقاس النافد.
- [ ] جرّبت إتمام طلب كامل، ووصلت الرسالة إلى واتساب بالتفاصيل الصحيحة.
- [ ] تحققت من المتجر والسلة وإتمام الطلب على هاتف Android وiPhone.
- [ ] تحققت من الروابط في الهيدر والفوتر.

### تشغيل الموقع محلياً قبل الرفع
المتصفحات تمنع تحميل `products.json` عند فتح الملفات مباشرة (`file://`). لذلك شغّل خادماً بسيطاً:

```bash
cd spidbrick
python -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## 8. أسئلة متكررة

**هل الموقع آمن للدفع؟** لا يوجد دفع إلكتروني أصلاً. الدفع نقداً عند الاستلام. لا تُخزَّن أي بيانات بنكية.

**أين تُحفظ الطلبات؟** لا تُحفظ على الموقع. تصل إلى واتساب المتجر. آخر طلب فقط يبقى في متصفح الزبون لعرضه في صفحة التأكيد.

**هل يمكن أن يرى الزبون لوحة الإدارة؟** نعم، الصفحة موجودة على الرابط نفسه لأن الموقع ثابت. لكن أي تعديل فيها يبقى داخل متصفحها فقط ولا يغيّر الموقع للآخرين. مع ذلك، لا تضع فيها أي شيء سري.

**هل يمكن إضافة الفرنسية؟** الواجهة الحالية بالعربية. لإضافة الفرنسية نسخ النصوص إلى قاموس ترجمة وتبديلها بحسب اختيار الزبون، ويمكن إضافة ذلك لاحقاً دون تغيير البنية.

**هل يمكن ربط الموقع بخدمة توصيل أو دفع إلكتروني لاحقاً؟** نعم، لكن ذلك يتطلب خادماً أو خدمة مدفوعة (مثل بوابة دفع)، وهو خارج نطاق النسخة المجانية.

## 9. ملاحظات تقنية

- جميع الروابط داخلية بمسارات نسبية، لذلك يعمل المشروع داخل مستودع فرعي مثل `/spidbrick/`.
- الخط المستخدم من Google Fonts مجاني. إذا تعذّر تحميله يظهر خط احتياطي دون أن يتعطل الموقع.
- السلة وإعدادات المتصفح تُحفظ في `localStorage` تحت المفاتيح `spidbrick_cart_v1` و`spidbrick_catalog_override_v1` و`spidbrick_last_order_v1`.
- تأكد من الحفاظ على ملف `.nojekyll` في جذر المستودع.
